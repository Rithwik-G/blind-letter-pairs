
# Minimalist UI for Storing Blind Letter Pairs (`memo`)

Use at [memo.rithwikg.com](https://memo.rithwikg.com/)

The active app stores data in the browser with `localStorage`, so it opens without an account. Data stays in that browser profile; use CSV export for backups or moving it elsewhere. The original Supabase client, authentication screen, and cloud-storage path remain in the source but are not active by default.

## Features

1. Upload from CSV. Download your Google Sheets and upload them directly.
2. Download Anki-usable Flashcards
3. Automatically remove pairs not required for your buffer system
4. Right-click to change cell color, use this for pairs you are iffy about
5. Save letter pairs in your browser
